**检测核心重写（`ammo_detect.py`）**：
- **双通道**：白色通道严格形状校验 + 精确填充率；**红色通道只确认「处于低弹红色状态」**（用户要求：红不好测就整条 UI 显示红，不苛求百分比）。

- **多区域粘性 fallback**：A 组 (330,1250)-(390,1300) 优先，A 无弹匣看 B 组 (230,1245)-(270,1300)，都无则输出「未检测到」。锁定某组后只截该组。

**踩过并修掉的坑**：
1. **不能用「窗口邻域」裁剪掩膜** —— 会把方形等其它图标也裁成窗口形状，形状 IoU 从 正0.92/负0.30 退化成 正0.61/负0.53，完全失去分辨力。正确做法：取完整掩膜的最大连通域 + 用位置交叠做否决（不裁剪）。
2. **旧实现 `lum > 120` 绝对亮度下限在暗场景会整条滤掉轮廓**（实测某帧最亮才 156）。改为主用相对判据 `lum > 本行背景 + margin`，`lum_floor` 降到 55。
3. **黄沙/棕土背景会被误判成红** —— 加 `r > g*1.4 且 r > b*1.4` 后视频误报从 19% 降到 5%。但**不能超过 1.4**：用户屏幕的暗红低弹帧 r/g 中位只有 1.30，1.6 会把低弹状态全杀掉。
4. **`_full.png` 上画了红色标注框**，直接切片会把框线带进来判成 red。全屏切片测试一律内缩 4px，或直接用 `_1x.png`。
5. **mss 每次 grab 有 ~8ms 固定开销，与区域大小几乎无关**。双区域各截一次 → 32ms/帧。改成未锁定时一次截并集 (160x55) 再切片 → **13.7ms/帧，稳定 50.2Hz**。

## 23:00 启动器 launch.py（Steam 同时启动 + 随游戏关闭自动关闭）

- 两种模式：① 默认一次性——未跑游戏就用 `os.startfile("steam://rungameid/553850")` 让 Steam 拉起，检测到进程后启动 live_ammo，之后每秒盯梢，游戏进程消失超过 `--exit-grace`（默认 3s）就杀掉叠加层并退出；等待超过 `--boot-wait`（默认 300s）仍无游戏则放弃，不留孤儿。② `--daemon` 守护——不碰游戏，谁拉起游戏就跟谁走（Steam 库/桌面图标/串流都行），游戏起来挂叠加层，关掉就撤。

- 子进程环境固定 `PYTHONIOENCODING=utf-8` + `PYTHONUNBUFFERED=1`：不设的话 Windows 默认 GBK，写管道/日志时父进程按 UTF-8 解会 `UnicodeDecodeError`（实测踩到）。
- 验收（用 `ping.exe` 冒充游戏，避免 notepad 同名进程干扰——第一次用 notepad 测时因系统里还有别的 notepad 进程导致"游戏一直没退出"的假阳性）：一次性模式游戏关闭后 **2.0s** 收摊、子进程已清理、退出码 0；守护模式 出现→挂载 / 消失→撤销 / 再出现→重新挂载 全对，两次挂载的子进程均清理干净；`--no-launch` 超时 3s 放弃、`--attach` 游戏没跑直接报错，两条边界路径退出码均为 1。

## 23:40 A 区读数砍半：改用「当帧检出的弹匣自身」当分母（撤掉 fill_gain）

- 根因（量化）：标定用的固定窗口掩膜 `assets/a_interior_mask.npy` 与弹匣实际位置错位 —— 掩膜 bbox x[24,44]，弹匣连通域 bbox x[30,53]，**IoU 仅 0.374**。掩膜只盖住弹匣左半边（掩膜∩弹匣 287px，弹匣自身白 570px），分子被砍半 → 稳定显示 52.7%。
